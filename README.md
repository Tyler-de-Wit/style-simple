# Style Simple

Simple to use CSS Library.

## Description

This is a CSS library built with SASS which aims to have easy to use syntax and components that offer more customisability so they don't look like they came from a CSS library.

## Getting Started

### Dependencies

- npm

### Installing

- Clone the repository

### Executing program

1. Install the dependencies
2. Live compile the SASS
3. Open the index.html file in a browser to view styles

```bash
npm install
npm run watch
```
